# Changelog

## 0.2.0 — 2026-10-09

- Атомарная защита от перезаписи проекта другим окном; сохранение своих правок отдельной копией.
- Общие квоты переноса: snapshot/ZIP до 64 MiB, распакованный пакет до 128 MiB. Аварийная JSON-копия для крупных локальных проектов.
- Fixtures формата 0.1 и каркас миграций с исходным backup до преобразования; текущий формат не меняется.
- Общий реестр действий клавиатуры, палитры и контекстного меню, проверка доступности и областей ввода.
- Два локальных профиля, отдельные предпочтения и последний проект; первая настройка с практикой, локальными рекомендациями, пропуском и повтором.
- Обновлённый альманах, правила участия, шаблоны issues/PR и воспроизводимые notices сторонних библиотек.

Лицензия проекта — GPL-3.0-or-later. Copyright-заголовки проверяются при сборке и в CI. Исходники опубликованы в quartz2004-lgtm/Workflow-Architect, включён частный канал сообщений об уязвимостях. Проверки GitHub Actions для Linux и Windows прошли. Формат проекта остаётся 0.1; runtime и вызовы ИИ в этот выпуск не входят.

## 0.2.0-alpha.1 — 2026-10-09

Первая итерация v0.2: стабильность редактора и контекстная справка.

- Хоткеи используют физические клавиши и работают в русской раскладке. Ctrl+F/K доступны из полей ввода; текстовые copy/paste/select/undo сохраняют обычное поведение.
- Duplicate без выделения ничего не вставляет и не заменяет внутренний буфер копирования.
- Собственные сохранённые проекты больше 10 MiB снова открываются и корректно отображаются в списке. Проверка версии, схемы и очевидных секретов сохраняется. Внешний импорт по-прежнему ограничен 10 MiB.
- Подсказки у заголовков полей Inspector, контрактов, портов, групп, ресурсов и настроек проекта: наведение, фокус, Escape, переход к главе альманаха.
- Общий каталог текстов подсказок и альманаха; обновлена автономная HTML-копия.
- Добавлены регрессионные проверки и GitHub Actions для браузера и Windows. CI требует размещения репозитория на GitHub; публикация сборок не автоматизирована.

Формат данных — `schemaVersion: "0.1"`, без миграции. Живая Codex/MCP-интеграция и runtime не добавлялись.

Проверено локально 09.10.2026: typecheck, lint, production build, 50 unit/integration tests, 19 browser scenarios, 4 desktop scenarios на упакованном и установленном приложении. Hosted CI ещё не запускался: удалённый репозиторий не подключён.

Windows installer: `Workflow-Architect-0.2.0-alpha.1-Setup.exe`; SHA-256 `EE90C12632F78000BDB1D836FEEFDB3AC36837FE45C2BD5955B5CC7209F51CCA`.
