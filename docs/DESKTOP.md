# Workflow Architect для Windows 11

## Запуск

Установщик: `release/Workflow-Architect-0.2.0-Setup.exe`.

Установите для текущего пользователя и откройте **Workflow Architect** через ярлык на рабочем столе или меню «Пуск». Node.js, терминал, сервер и интернет для работы установленного приложения не нужны.

Также можно запустить `release/win-unpacked/Workflow Architect.exe`. Для переноса этой версии нужна **вся папка** `win-unpacked`, а не один exe.

## Первые действия

1. При первом запуске пройдите настройку профиля или пропустите её. Затем нажмите название проекта сверху → выберите один из трёх примеров или создайте свой проект.
2. Добавляйте Concept и engineering nodes слева, связывайте порты, редактируйте свойства справа.
3. `Ctrl+K` открывает команды, `Ctrl+F` — поиск, `Ctrl+Z` — отмену. **F1 / ?** или кнопка **«Альманах»** открывает полное руководство из 29 глав с поиском. Его можно сохранить как автономный HTML для чтения и печати.
4. «Validate» показывает структурные ошибки; «Preview» демонстрирует обход графа без выполнения агентов.
5. «Экспорт» → выберите snapshot, архив, Markdown или Codex package → сохраните через стандартное окно Windows.

## Данные

Проекты автоматически сохраняются в IndexedDB профиля `%APPDATA%\Workflow Architect`. При закрытии приложение сначала фиксирует редактируемое текстовое поле и завершает autosave. Если сохранение не подтверждено, выход требует явного выбора. JSON-поля сохраняются кнопкой «Применить JSON».

Desktop и браузер имеют отдельные хранилища. Для переноса используйте JSON/YAML snapshot или ZIP через менеджер проектов. Регулярный экспорт snapshot подходит для резервной копии. Деинсталлятор сохраняет профиль.

Приложение работает офлайн; модельные API и внешние tools не выполняются. Экспортируемый пакет предназначен для дальнейшей реализации workflow. Установщик локальной Alpha не имеет сертификата подписи издателя.

## Сборка из исходников

```sh
npm ci
npm run desktop:build
```

Результат появляется в `release/`. Первой сборке нужен интернет для загрузки Electron и NSIS. Для разработки desktop без установщика:

```sh
npm run desktop:prepare
npm run desktop:start
```

Проверки:

```sh
npm run check
npm run test:e2e
npm run desktop:prepare
npm run test:desktop
```

Desktop-тест запускает настоящее Electron-окно с отдельным временным профилем: CSP/bridge, ввод, закрытие без ожидания debounce, повторный запуск, ZIP-экспорт и повторный импорт. Для проверки установленной сборки задайте `DESKTOP_EXECUTABLE` абсолютным путём к exe перед `npm run test:desktop`.

Архитектурное решение: [ADR 0005](decisions/0005-windows-desktop.md).

Installer не подписан сертификатом издателя; автоматическое обновление не настроено. Аварийное завершение процесса или отключение питания не может гарантировать сохранность правок, которые ещё не были записаны в IndexedDB.
