# ADR 0005 — Windows-приложение как отдельная оболочка

Статус: принято. Дата: 2026-10-08.

## Контекст

Пользователь запросил готовый веб-интерфейс либо приложение для Windows 11 и делегировал выбор. Веб-редактор Alpha уже реализован. Выбрано настольное приложение с установщиком, собственным окном и локальным профилем.

Спецификация предпочитает Tauri при отсутствии ограничений. На рабочем ПК отсутствуют Rust/Cargo и MSVC build tools. Для сборки в имеющемся Node.js-окружении используем Electron. Цена решения — больший дистрибутив и отдельные обновления Chromium/Electron.

## Решение

- `desktop/` содержит native lifecycle, защищённый протокол статических ресурсов, окно и сохранение перед закрытием.
- React-приложение загружается с постоянного origin `workflow://app`. HTTP-сервер, сеть, аккаунт, Node.js на ПК пользователя не нужны.
- Renderer sandboxed, `nodeIntegration: false`, `contextIsolation: true`. CSP запрещает eval, удалённые scripts, frames и формы. Внешние запросы, переходы, новые окна и разрешения запрещены.
- Единственный preload bridge — запрос сохранения перед закрытием. Он не раскрывает filesystem, shell, generic IPC или runtime execution.
- Main проверяет отправителя и request ID ответа. При ошибке/таймауте пользователь возвращается в редактор либо явно выходит без сохранения.
- Экспорт использует штатное окно сохранения Electron; импорт — существующий file input. Формат проекта и exporters остаются общими с веб-версией.
- IndexedDB находится в профиле приложения. Данные браузера не копируются неявно: перенос выполняется экспортом/импортом.
- NSIS устанавливает приложение для текущего пользователя без администратора. Деинсталляция сохраняет профиль.
- Staging содержит production assets, shell и минимальный package.json без npm runtime dependencies. Исходники и development tools не попадают в установку.

## JSON Schema и CSP

Ajv обычно компилирует встроенные метасхемы при первом обращении через `new Function`. Для строгой CSP доверенные метасхемы draft-07 и 2020-12 заранее генерируются `scripts/generate-metaschemas.mjs` и сохраняются в `src/validation/generated`. Пользовательские schemas проверяются статическими функциями. Внешние метасхемы не загружаются. Обновление Ajv сопровождается `npm run schemas:generate` и тестами.

## Последствия

Domain model, команды, история, Canvas adapter и формат 0.1 не меняются. Замена Electron на Tauri затронет оболочку и узкий platform bridge. Автообновления, подпись дистрибутива, runtime, MCP и облачная синхронизация в эту итерацию не входят.
