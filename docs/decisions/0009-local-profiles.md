# ADR 0009: локальные профили отдельно от проекта

Статус: реализовано в ветке разработки 0.2.0.

Два именованных профиля хранятся в отдельной IndexedDB `workflow-architect-profiles`. Собственный формат 0.1 проверяется Zod. Фиксированные UUID двух начальных слотов и атомарное создание исключают дубликаты при одновременном первом запуске. Revision предотвращает молчаливую перезапись настроек другим окном. Повреждённые данные не заменяются defaults автоматически.

Профиль содержит ответы первой настройки, предпочтения интерфейса, избранные шаблоны и рекомендуемые будущие лимиты. Он не является частью сериализованного workflow и не меняет формат проекта 0.1. Рекомендации на этом этапе вычисляются локальными объяснимыми правилами, без модели и сетевых запросов. Рекомендуемые лимиты не исполняются до появления runtime.

Список проектов общий для этого устройства; последний открытый проект хранится отдельно по каждому профилю. Только первый профиль наследует прежний `active-project`, пока не сохранит собственный выбор. Профили персонализируют интерфейс, но не являются границей безопасности или разделением Windows-учётных записей. Будущие credentials и права потребуют отдельной модели.

Переключение профиля должно сначала завершить сохранение проекта. Ошибка или конфликт оставляют текущий редактор открытым. Первичная практика работает в изолированном состоянии и не изменяет пользовательский проект.
