# ADR 0004: Recovery copies, transient Preview и совместимые настройки

Статус: принято для Alpha polish.

## Восстановление

Повреждённый snapshot 0.1 не подменяется пустым проектом. `recoverProject` независимо от UI пытается прочитать совместимые поля и сущности. Если конфигурация узла повреждена, сохраняются его валидные ID, текст, геометрия, порты и совместимые поля config; повреждённые части заменяются безопасными значениями или исключаются. Неизвестные типы восстанавливаются как Concept. Неразрешённые ссылки остаются видны domain validator.

Пользователь видит отчёт с путями ошибок, исходными записями и кнопкой открытия восстановленной копии. Копия всегда получает новый project ID; исходная запись IndexedDB не перезаписывается. Отчёт и raw JSON хранятся в отдельном transient recoveryStore; в экспортируемый проект не попадают. Из отчёта можно перейти к восстановленному узлу. После reload открывается сохранённая исправленная копия; исходный повреждённый проект остаётся в списке локальных проектов, и отчёт можно построить снова.

Неизвестные версии и синтаксически неразбираемый JSON не исправляются догадками. Для них доступны исходный файл и создание нового проекта. Recovery ограничен 10 MiB. Восстановление из import UI доступно для самостоятельного JSON snapshot; ZIP/YAML проходят строгую проверку. Это не общий migration engine.

## Preview

`preview/plan.ts` строит ограниченный обход domain graph. Посещает все ветви Flow/Data и вложенные графы; циклы и несвязанные компоненты не приводят к бесконечному обходу. Узел посещается не более одного раза. Note и disabled исключены, Reference/Tool access не задают порядок обхода. Conditions, expressions, AI и инструменты не исполняются.

Отдельный preview controller содержит steps/index/status и таймер. Running/Success — только временный overlay, не persisted node status. Изменение проекта, undo/redo и переключение проекта останавливают Preview. Reduced motion запускает его на паузе для ручных шагов. Errors блокируют старт и ведут к diagnostics; warnings допустимы. UI явно называет это обходом архитектуры.

## Настройки и визуальные размеры

В settings 0.1 добавлено необязательное `exportDefault` с вариантами archive/json/yaml/markdown/codex. Отсутствие поля означает archive. Старые snapshots читаются без изменения; настройка редактируется обычной командой и поддерживает undo/redo. Это аддитивное расширение, не переинтерпретация существующих данных.

Автовысота — явная команда «Автовысота по содержимому». Canvas измеряет временную копию карточки и передаёт ограниченную 100–1200 px высоту через resize command. Результат сохраняется как обычный domain size и отменяется одним undo. После изменения текста команду можно повторить; автоматические измерения не создают скрытые записи истории на каждом keystroke или zoom.

## Проверки

Unit tests проверяют частичное восстановление и сохранность валидных полей, version rejection, исключение секретов из копии, Preview traversal/pause/timers и отсутствие влияния на project/history. Playwright проходит damaged boot → recovery copy → исправление → autosave → reload и сверяет исходную IndexedDB запись побайтно. Отдельный Preview-сценарий проверяет reduced motion и временность подсветки.
