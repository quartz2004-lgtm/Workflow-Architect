# ADR 0010 — декларативное локальное выполнение

Статус: принято для реализации 0.3.0, 12.10.2026.

## Решение

Исполнитель принимает версионированный план, построенный чистым компилятором из проверенного domain snapshot. Формы сохраняют декларативные операции в проекте; свободный текст из прежних полей не получает неожиданную исполняемую семантику. Формат проекта изменяется явно с 0.1 на 0.2, с backup до миграции. Версия плана независима от версии документа и приложения.

Исполнение находится вне React и Canvas в Web Worker. Чистые операции не имеют capabilities файловой системы, shell или сети. Worker не рассматривается как универсальная песочница произвольного кода: пользовательский код вообще не поддерживается. Строки обрабатываются как данные. Renderer получает только события и результаты через валидируемый протокол; произвольного IPC для команд ОС не добавляется.

Каждый run владеет копией плана. Edit/undo меняет следующий запуск, а не текущий. Run state отделён от project/history и Preview. При закрытии приложения выполнение 0.3.0 прекращается; надёжный отдельный фоновый процесс, credentials и восстановление — этап 0.3.1. Транспорт можно заменить без изменения domain-операций и семантики компилятора.

Контракты исполняются безопасным интерпретатором ограниченного явно документированного JSON Schema. Неподдержанные ограничения блокируют запуск; нет eval, загрузки внешних refs или молчаливого принятия непроверенных контрактов.

## Последствия

Нет готового движка, который мог бы диктовать формат Canvas или сохранения. Семантика маршрутизации, входов Subworkflow, циклов и Human фиксируется и тестируется до добавления Agent. Web и Windows используют одно ядро и протокол. Чистое ядро пригодно для последующего фонового runtime, не обещая его поведение в 0.3.0.

Конкретные критерии приёмки и ограничения: [V0.3.0_PLAN.md](../V0.3.0_PLAN.md).
