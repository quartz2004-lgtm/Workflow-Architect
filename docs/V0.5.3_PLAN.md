# 0.5.3 — источники и фотографии в контексте агента

Статус: разработка. Требования: ROADMAP.md, 0.5.3; фотографии добавлены по прямому поручению владельца.

## Последовательность

1. Чистый локальный retrieval/context builder: атомарные JSON-записи и Markdown-блоки, точные ID/SKU, ранжирование, бюджет, явные пробелы и источник каждой выдержки. Не менее 30 заранее размеченных вопросов, включая отсутствующие/конфликтующие факты и инструкции внутри данных.
2. Явная конфигурация знаний Agent со стабильными ссылками и версионированием формата проекта. Runtime фиксирует разрешённые снимки до начала исполнения; обновление/удаление исходной базы не меняет доказательства запуска. Manual и Telegram используют один путь через JobManager/ExecutionRun.
3. Локальные фотографии JPEG/PNG: безопасный импорт, ограничения размера, каноническая копия без EXIF, SKU и описание, отдельные разрешения профиля. Выбранные пиксели передаются только Vision-модели. Проверка контекста резервирует место фотографии и ответу; неподдерживаемая модель не получает подмену изображений подписью.
4. Inspector и «Что прочитал агент»: выбор коллекций/изображений, проверка поиска, неизменяемые фрагменты и превью фактически переданных изображений в истории. Никакого автоматического объявления модельных наблюдений утверждёнными фактами.
5. Реальная база SOAR и Mistral: текстовый и визуальный приёмочные сценарии, локальность, качество поиска отдельно от качества генерации. Все необходимые software checks, обновление альманаха/ADR/архитектуры, Windows-установщик, backup, CI, PR, тег, публичный Release и проверка установленной сборки.

## Инварианты

- Экспортируемый проект содержит ссылки и настройки, не содержимое базы, изображения или секреты. Пользовательская база не попадает в Git или release assets.
- Документы/изображения — недоверенные данные. Они не меняют system policy, permissions и список инструментов. Наблюдение по фото не доказывает состав/медицинское действие.
- Нет скрытого сетевого поиска, embeddings download или облачного fallback. Отсутствие факта, переполнение бюджета и несовместимость модели видны человеку.
- Обновление с 0.5.2 сохраняет коллекции, проекты, профили и историю. Старые snapshots остаются читаемыми; новые форматы имеют явную версию.
- Приёмка покрывает полный путь, а не только красивый preview или mock ответа модели.
