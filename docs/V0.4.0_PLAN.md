# План выпуска 0.4.0

Статус: реализация и приёмка локальной модели завершены; публикация и установщик фиксируются в GitHub Releases.

Основание: утверждённый ROADMAP, раздел 0.4.0. Первая интеграция — локальная Ollama; модель Qwen3 8B под RTX 5070 (12 GB), с проверкой фактических возможностей. Пользователь разрешил установку модели. Приёмка: русская статья «Как выбрать бельё для комфорта», общая аудитория, минимум 600 слов.

## Последовательность

1. **Граница ИИ.** Независимый от UI и поставщика протокол сообщений, валидируемые настройки и ответы, Ollama-адаптер в доверенном runtime, проверка модели/инструментов/JSON. Ограничения размера, времени, контекста и токенов; отмена. Подключение принадлежит профилю, адрес и credentials не попадают в проект. Редактор без модели продолжает работать.
2. **Исполнение.** Версионированные операции Agent и встроенного Tool, явные разрешения, ограниченный цикл вызовов, структурированный результат, журнал и учёт токенов. Последовательные агенты и ограниченный параллелизм с однозначным объединением. Незавершённый запрос при аварии не повторяется скрытно. Старые проекты и история остаются читаемыми.
3. **Рабочий интерфейс.** Подключение/проверка модели, настройки Agent, просмотр вызовов, готовый пример «Автор → Редактор» с инструментом проверки текста. Помощник уточняет запрос, предлагает изменение графа, показывает предварительный результат и применяет единой undoable-командой. Анализ анкет и пробной задачи предлагает 2–3 объяснимых варианта профиля: применение вручную, редактирование и возврат. ИИ не меняет credentials и разрешения.
4. **Приёмка и выпуск.** Реальная локальная модель, статья, инструменты, ошибки/отмена/лимиты, восстановление, изоляция профилей, параллельные результаты, подтверждение предложений и undo. Unit/browser/desktop проверки, typecheck/lint/build, copyright и зависимости, визуальная проверка, справка. Installer и проверка обновления с резервной копией; зелёный CI, commit/tag/GitHub release, проверка опубликованных файлов.

## Условия выпуска

- Ни один обязательный пункт ROADMAP 0.4.0 не заменён демонстрацией или mock.
- Автотесты транспорта используют поддельный сервер; отдельная приёмка использует реальную модель и сохранённые результаты.
- Любые ограничения возможностей видны в интерфейсе и справке. Telegram/HTTP-коннекторы/MCP остаются 0.5.0, Git/VS Code/Codex — 0.6.0.
- Выполнение команд и произвольного кода не добавляется как обход отсутствующего инструмента.
- Успешная генерация текста не равна фактчекингу: пример проверяет длину/структуру, редактор не приписывает себе поиск источников.

## Ход разработки

- Провайдерное ядро и ограниченный tool loop: реализованы, отдельный commit.
- Формат проекта 0.3, миграции 0.1/0.2, планы 0.4, последовательные/параллельные Agent, native profile connections: реализованы, отдельный commit.
- UI подключения, помощника, персонализации, Inspector и пример статьи: реализованы. Альманах расширен до 32 глав.
- Финальная проверка ядра: 181 unit-тест, typecheck/lint/build, copyright и notices; 26 browser-сценариев. Фиксированный snapshot 0.2 мигрирует и выполняется с прежним результатом. Production-профили 100/300 узлов прошли; [метрики](PERFORMANCE.md).
- Реальная приёмка 12.10.2026: Ollama 0.40.3, qwen3:8b Q4_K_M, RTX 5070 12 GB, контекст 32768. Digest модели: `500a1f067a9f782620b40bee6f7b0c89e17ae61f686b92c24933e4ca4b2b8b41`.
- Все четыре `npm run test:ai:local` сценария прошли: два агента и обязательный Tool; capabilities + проектирование/применение + три варианта персонализации; отмена; две параллельные ветви и однократный Merge. Другая учётная запись приложения подключения не получила.
- Статья по заданию пользователя: 644 слова, 31.1 секунды, 3 model calls, 1 tool call, 4831 входной и 3146 выходных токенов. Результат и полный журнал сохранены локально в `output/ai-acceptance/`. Это проверка исполнения, не редакционное одобрение: модель допустила неточные советы о размерах и тканях, текст требует проверки человеком. Источники модель не искала.
- Исходные четыре пользовательских проекта зарезервированы перед установкой. Проверены чтение старой и новой сборками и миграция с сохранением содержимого и исходного backup. Публикационный checklist: packaged/installed desktop smoke, upgrade, CI, tag и release assets.
