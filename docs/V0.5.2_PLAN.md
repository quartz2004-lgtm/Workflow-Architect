# 0.5.2 — локальная база знаний SOAR

Статус: реализация, локальная приёмка и установка завершены; публичный статус — GitHub Release v0.5.2. Основание — ROADMAP.md, этап 0.5.2.

## Архитектура и порядок

1. Независимые схемы коллекции, документа и неизменяемого снимка; ссылки по UUID, контроль содержимого SHA256. Проект и Canvas не меняются.
2. Native knowledge service с отдельным каталогом данных приложения и проверкой владельца профиля. Подключённая папка остаётся внешним источником истины. Выбранные Markdown/JSON копируются в снимок, исходники не изменяются. Каталог документов восстанавливается из снимка; отдельная поисковая БД для этого этапа не нужна.
3. Импорт в два шага: выбор разрешённых файлов и предварительный просмотр → подтверждение подготовленного снимка. Новые файлы не получают разрешение автоматически. Обновление учитывает содержимое незакоммиченных файлов. Ошибка, конфликт ревизии или повреждение не заменяют рабочую версию.
4. Мастер «Знания SOAR»: папка, список файлов, обновления/удаления, статус версии, просмотр текста и метаданных, история, резервная копия и восстановление. Видимая граница: автоматическая передача знаний Mistral появится в 0.5.3.
5. Unit/native UI проверки импорта, обновления, удаления, повреждения, восстановления, изоляции и перезапуска без источника/сети. Затем общие проверки, сборка, документация, Git/CI/Release и установка с резервной копией.

## Приёмка

- Нельзя обойти разрешённые корни через traversal, symlink/junction, архивы или служебные каталоги; секретные/персональные источники не выбираются автоматически.
- Неизвестные значения и статус согласования не додумываются. SKU и исходные ID сохраняются только из явных полей; редакционное согласование не становится доказательством свойства.
- Удалённые документы отсутствуют в новом снимке, старые видны только в истории. Последние три снимка хранятся локально; старые можно удалить явно. Будущие run snapshots имеют отдельную политику и здесь не реализуются.
- Резервная копия проверяется по схеме и хешам, восстанавливается отдельной коллекцией текущего профиля без автоматического доверия прежнему пути.
- Доступ к снимку после перезапуска не зависит от источника и интернета. Никакие тексты не исполняются и не отправляются модели/в сеть.
